# AllsAmple 0.1.2

- DOVA-SYNDROME（現OpenTracks）を追加。BGM・ジングル・効果音を「雨」などで横断検索できます。
- ダウンロードフォームが公開する配布MP3を優先。取得制限時は試聴用と明示した音源へ切り替えます。
- 作者独自の条件が未確認の素材を条件付き表示にし、サイト準拠を確認できた素材は表示を更新します。音源の再配布・Content ID登録は不可として扱います。
- 波形、比較、保存、外部ファイルD&D、お気に入り・使用素材リストに対応。
- 旧設定からの更新時はDOVAを検索対象へ追加。その後に外した選択は再起動後も尊重します。

この追加はチェック欄・保存IDも増えるため、初回は本体0.1.2への更新が必要です。MacはUniversal ZIP、Windowsはx64インストーラーです。

[使い方](https://github.com/nisesimadao/AllsAmple/blob/main/INSTALL-ja.md)

# AllsAmple 0.1.1

- Spliceの試聴データを通常のMP3として扱っていたデコード失敗を修正。旧キャッシュも読み出し時に修復します。
- 音声を先に再生し、波形は後から生成。ホバーは短い待ち時間後の音声先読みに限定しました。
- 読み込み中の停止・連続切り替えで、古い成功・失敗が現在の再生へ割り込む問題を修正。
- 日本の3サイトも段階的に音声を配信。長さ不明の応答にも対応し、波形・保存は全データ取得を待ちます。
- 通常速度ではピッチ変更用ワークレットを通さず再生。素材一覧全体の重複保存も削減しました。
- On-Jinの音源URLが変わった場合は、同じ素材の現在のリンクを取得し直します。
- 行のタイトルから音声ファイルを外部へドラッグ。オンライン音源はDownloadsへ保存して渡し、波形の完成は待ちません。macOS / Windows共通実装です。

MacはUniversal ZIP、Windowsはx64インストーラー。Windows実機と個々のDAWへのドロップ受け入れ確認は未実施です。

[インストールと使い方](https://github.com/nisesimadao/AllsAmple/blob/main/INSTALL-ja.md)

# AllsAmple 0.1.0

9つの音素材サイトとローカルフォルダを、ひとつの検索窓で探すデスクトップアプリです。

- 日本語の類義語を展開して横断検索。サイトごとの結果を独立して表示。
- ↑ / ↓とSpaceで試聴。実音声から描いた波形で頭出し、速度・ピッチの独立調整。
- 4候補の比較トレイとブラインド比較。
- 素材別の利用条件、規約リンク、プロジェクト別のクレジット.txt。
- 原形式のまま保存、パスコピー、フォルダ表示、一括書き出し。
- 小さなサイトモジュールをGitHub Releasesから取得し、次回起動時に読み込み。本体の自動差し替えは行いません。

MacはUniversal ZIP、Windowsはx64インストーラーです。正式署名・公証はしていません。Windows実機での動作確認は未実施です。

[インストールと使い方](https://github.com/nisesimadao/AllsAmple/blob/main/INSTALL-ja.md)

素材は同梱しません。試聴用音源か元の配布素材かは画面で区別し、利用条件は各素材の規約で確認できます。
