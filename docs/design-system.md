# UIの共通ルール

画面構成は音源ブラウザとして保ち、色と操作部品に同じ基準を使う。React等のUIフレームワークは追加しない。

## 使用するもの

- [Radix Colors](https://www.radix-ui.com/colors): darkのGray / Slate、利用条件用のGreen / Amber / Orange / Red。
- [Lucide](https://lucide.dev/): 操作・状態アイコン。必要な22種類だけをSVGとして生成する。
- OS標準の日本語UI書体。数値・時刻には等幅書体。

どちらも開発時の依存だけで、実行時のパッケージや外部CDNは不要。SVGとCSSをアプリに同梱する。

## トークン

| 用途 | ルール |
| --- | --- |
| 背景 | Gray 1が作業面、Gray 2がサイドバー・詳細・再生バー |
| 操作の面 | Gray 3が通常、4がホバー、5が押下。選択行はSlate 5 |
| 境界 | Gray 6が区切り、7がコントロールの枠 |
| 文字 | Gray 12が本文、11が補足。色の用途を装飾のために増やさない |
| 利用条件 | Green / Amber / Orange / Redの11。灰色はGray 11。必ずアイコンと文言を添える |
| 文字サイズ | 本文12px、補足11px、詳細タイトル18px。320pxの補助情報だけ9〜10px |
| 余白 | 4 / 8 / 12 / 16 / 24px |
| コントロール | 高さ32px、主操作36px、角丸4px |
| アイコン | 24のviewBox、表示16px、線幅1.75、丸い端点。補助アイコンは12〜14px |
| キーボード | フォーカスを2pxの枠で表示。アイコンボタンにも操作名を付ける |

`palette.css`に元の色、`design-system.css`に用途と部品のルールを置く。既存のレイアウトは`style.css`に分離する。
実際の波形もCSSのSlate / Grayの色で描画する。

## アイコン

文字の`▶`、`☆`、`×`等でボタンを代用しない。再生、停止、検索、保存、閉じる操作はLucideのSVGへ統一する。
キーボードの矢印や速度の掛け算記号など、文字そのものが意味を持つ箇所は文字で表示する。

静的な部品はSVGスプライト、頻繁に更新する行・詳細はインラインSVGを使う。動的なアイコンを描くたびに外部SVGの描画待ちを作らない。
アプリアイコンとサイドバーは同じAudio Linesの形を使う。

```sh
npm run assets:ui
npm run icons
npm run test:ui
npm run docs:screenshots
```

`assets:ui`は必要なSVG・配色・ライセンスを生成し、`icons`は同じロゴからmacOS / Windows用のアイコンを生成する。
画面確認・スクリーンショット撮影はウィンドウ非表示で行う。
